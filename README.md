# Armana proposals to the Koinos Fund System

Full texts of Armana's proposals to the Koinos Fund System (KFS), the on-chain
treasury that funds community projects by token-weighted vote. Submission and
voting happen at https://kfs.koinscan.com.

Each proposal lives in its own folder named for the month it starts, and is
served as a plain HTML page through GitHub Pages:

| Proposal | Term | Page |
|---|---|---|
| Armana infrastructure and apps for Koinos | Nov 2026 – Apr 2027 | https://armana-group.github.io/kfs-proposals/2026-11/ |

## Freeze policy

The on-chain description of a proposal links to its page here, and the chain
record cannot be changed. So once a proposal has been submitted its page is not
edited. If something needs correcting later, a dated note is appended below the
original text and the change is visible in the git history. Each submission is
tagged (for example `2026-11-submitted`) at the commit that was live when the
proposal went on chain.

No build step, no dependencies: the pages are static HTML served straight from
the `master` branch.
